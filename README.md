
Modding with Kaupenjoe NeoForge for Minecraft 26.X
=======

This GitHub Repository is the result of my progression while following Modding By Kaupenjoe: NeoForge Modding for Minecraft 26.X

The Source Code will always be freely available under the MIT-License.

Take a look at the Course right here: <a href="https://courses.kaupenjoe.net" target="_blank">COURSE</a>

note to self:<br>
in case of missing libraries inside the IDE, or other problems:<br>
run `gradlew --refresh-dependencies` to refresh the local cache.<br>
run `gradlew clean` to reset everything (does not affect the code)
